What I'm building

An event management ecosystem: guests receive invitations, organisers run their events, and an internal crew keeps the whole thing moving. Flutter Web front to back, Spring Boot behind it.

Amantran India

The consumer-facing app: digital invitations, bookings, payments. Migrated the entire codebase from GetX to Riverpod without pausing feature work — including the full payment cluster.

Riverpod 3FreezedRazorpayBeamer

Organiser dashboard

Where event organisers manage their listings, seating and invoices. Purple surface, self-signup, built on the same shared kits as everything else.

Flutter Webseat_kitinvoice_kit

Ops console

Internal crew tool — event approvals, payments, support tickets, crew management. Invite-only, phone-OTP, and a deliberately different teal so nobody confuses it with the organiser app.

The kits

core_kit, theme_kit, auth_kit, invoice_kit, seat_kit. Dependency inversion at every seam: kits declare interfaces, apps inject the implementations. Semver'd, tagged, tested.
